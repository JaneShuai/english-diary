# 手绘治愈私密英语日记本 · 使用说明

一个**纯前端、断网可用、数据只存在你浏览器本地**的私密英语日记工具。打开网页即可用，无需联网、无需注册、无服务器。**可分享给多人共用**：同一台设备/同一个网页，每人一本独立日记，数据互不干扰。

---

## 一、怎么打开 & 分享

1. 把整个文件夹（含 `index.html`、`css/`、`js/`）放在任意位置。
2. 用浏览器（推荐 **Chrome / Edge**）直接打开 `index.html` 即可。
   - 双击文件，或把 `index.html` 拖进浏览器窗口。
3. 点 **开始记录**：
   - **第一次用**：填写名字、密码、英语等级，创建属于你的日记本。
   - **已有日记本**：在列表里选自己的本子、输密码进入。
4. **分享给同事/朋友**：把整个文件夹发给他们，或放到公司内网/任意静态空间，每个人打开后各自「创建新日记本」即可，互不干扰。

> 小提示：数据存在**各自浏览器**的 LocalStorage 里，**换浏览器 / 清缓存 / 用无痕模式** 都看不到之前的日记。重要日记记得用「导出」功能备份到本地文件。

## 三、配置有道翻译（联网增强，推荐国内用户）

实时中文→英文提示默认走你**自己部署的有道翻译代理**（国内快、稳定、密钥不暴露）。配置只需三步：

### 1) 获取有道 API 密钥（免费）
1. 打开 [有道智云](https://ai.youdao.com) → 注册并登录（需手机号，建议完成实名认证以解锁调用额度）。
2. 进入「控制台 → 应用管理 → 创建应用」，填名称/类别，提交后得到 **应用ID（App Key）**。
3. 在该应用里「绑定服务 → 文本翻译」，绑定后应用详情页会显示 **应用密钥（App Secret）**。
4. 新用户通常有免费调用额度，个人日记量很小基本够用，超出按字符计费。

### 2) 部署一个免费代理（Cloudflare Workers）
浏览器**不能**直接调有道（跨域被拦 + 密钥会暴露），所以用十几行代码的 Workers 做中转：
- 代理代码已附在仓库：`youdao-worker.js`。
- 打开 [Cloudflare Dashboard](https://dash.cloudflare.com) → Workers & Pages → 创建 Worker → 把 `youdao-worker.js` 内容全粘贴进去保存。
- 进入该 Worker → Settings → Variables → 添加环境变量（选 Encrypt 更稳）：
  - `YOUDAO_APP_KEY` = 你的应用ID
  - `YOUDAO_APP_SECRET` = 你的应用密钥
- 复制分配的地址，形如 `https://my-youdao.xxx.workers.dev`。

> 不想用 Cloudflare？任意能跑一小段代码的地方都行（Vercel 函数、你自己的服务器、Cloudflare Pages Functions 等），逻辑一致：前端把 `q` 发给你，你算签名调有道、带上跨域头返回即可。

### 2b) 快速自测：本机 Node 代理（免去注册 Cloudflare）
只想在自己电脑上立刻跑通、还没部署 Cloudflare 时，用仓库里的 `youdao-local-proxy.js`：
1. 打开 `youdao-local-proxy.js`，把 **App Secret（应用密钥）** 填到 `APP_SECRET`（已为你预填），把 **App Key（应用ID）** 填到 `APP_KEY`。
2. 在项目目录运行：`node youdao-local-proxy.js`（需 Node.js 18+）。
3. 终端显示「有道本地代理已启动：http://localhost:8787」即成功。
4. 网站设置 → 「有道翻译代理」填 `http://localhost:8787` → 打开「联网增强」。
- ⚠️ 该文件含你的密钥，仅本机使用，勿外发；要分享给他人请走 Cloudflare 版（密钥走环境变量）。

### 3) 在网站里填地址
设置页 → 「有道翻译代理」输入框粘贴上面的 `*.workers.dev` 地址 → 打开「联网增强」开关。
之后写中文时，下方就会实时弹出有道翻译结果。

🔒 **隐私承诺**：只会在你输入中文时，把**当前正在打字的那一句中文**经代理发往有道；**绝不上传**日记全文、用户名、密码、心情。断网或未配置代理时，自动降级为本地离线素材库兜底。

## 四、导出 PDF 怎么用

点「导出 PDF」会唤起浏览器打印窗口，在目标打印机处选择 **「另存为 PDF」** 即可保存到本地。
（这样能保证中文不乱码，且完全离线。）

```
youdao-local-proxy.js  有道翻译「本机」代理（Node.js，免注册即时自测，密钥仅留本机）
```

## 六、常见问题

- **忘记密码？** 密码只存本机，无法找回。可去「设置 → 数据管理 → 删除日记本」后重新创建（会丢失该本全部日记）。
- **多人共用会不会串数据？** 不会。每本日记独立密码、独立存储，互不可见。
- **换电脑/换浏览器日记没了？** 这是纯本地工具，数据不云同步，请用 TXT/PDF 导出备份后迁移。
- **中文实时提示不弹？** 先确认「设置 → 有道翻译代理」已填入你的 `*.workers.dev` 地址且「联网增强」已开；未配置代理会提示你去设置页填写。断网/代理不可用时自动用本地素材兜底。
- **字没对齐横线？** 行距设置会改变横线网格高度，文字会自动贴合行线；选「舒适」为默认对齐效果。
